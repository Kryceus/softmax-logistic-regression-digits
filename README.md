This project implements a multiclass logistic regression model, also known as softmax regression, from scratch in Python. It classifies handwritten digits from the Scikit-learn Digits dataset using 8×8 grayscale image inputs. The project focuses on the theoretical foundations of machine learning, including hypothesis functions, softmax prediction, cross-entropy loss, gradient descent, L2 regularisation, hyperparameter tuning, and model evaluation.

Key features
From-scratch softmax regression implementation
Scikit-learn Digits dataset
StandardScaler preprocessing
One-hot encoded labels
Mini-batch gradient descent
Cross-entropy loss
L2 regularisation
Hyperparameter tuning
Accuracy, confusion matrix, ROC-AUC, and loss curve evaluation
